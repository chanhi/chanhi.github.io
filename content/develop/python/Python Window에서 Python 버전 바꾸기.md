python을 최신버전으로 바꾸고 싶은데 이전에 쓰던 버전도 쓸 것 같아서 찾아보니 환경변수 설정을 바꿔주면 된다.

1\. 사용하고자 하는 python버전을 공식 페이지에서 다운을 받는다.

[https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/)

🔗 [Python Releases for Windows](https://www.python.org/downloads/windows/)

(설치할 때 Add to Path 체크박스 체크)

2\. 윈도우 검색에 <시스템 환경 변수 편집> or <window + R> 실행창에서 sysdm.cpl 실행

3\. 환경변수 클릭

4\. 변수 중 Path 편집 클릭

5.  사용하고자 하는 버전의 경로를 상단으로 올려준다. 끝!
